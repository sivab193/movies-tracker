# Security policy

Do not report vulnerabilities in a public issue or pull request.

Email `contact@media-verse.in` with:

- the affected URL, endpoint, or component;
- a minimal reproduction or proof of concept;
- the likely impact;
- any suggested mitigation;
- a safe way to contact you.

Do not include production credentials, access tokens, private user data, or destructive test results. Use test accounts and redact identifiers wherever possible. Please allow the maintainer time to investigate before public disclosure.

General bugs without a security or privacy impact should use the public [bug report form](https://github.com/sivab193/movies-tracker/issues/new?template=bug_report.yml).
